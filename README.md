### Currently Building

- **[GoFully](https://github.com/MUZEEBURRAHAMAN/gofully-extension)** — full-page screenshot Chrome extension with on-device OCR, a CleanShot-style annotation editor (arrows, shapes, blur/redact, crop), screenshot history, and PNG/JPG/WebP/PDF export. 100% on-device processing.
- **[Catchly](https://github.com/MUZEEBURRAHAMAN/Catchly)** — privacy-first subscription tracker that catches forgotten subscriptions and price hikes, all in your browser.
- **[Avatarly](https://github.com/MUZEEBURRAHAMAN/avatarly-figma-plugin)** — avatar generator plugin for Figma with 12 styles and 1,198 self-hosted avatars, zero third-party APIs.
- **[SafeSide](https://github.com/MUZEEBURRAHAMAN/safeside)** — native iOS food-ingredient scanner with transparent sourced scores and AI explanations.
- **[rareui](https://github.com/MUZEEBURRAHAMAN/rareui)** — a UI component platform to explore components, copy production-ready code, and paste Figma designs directly into your workspace.
- **[forge](https://github.com/MUZEEBURRAHAMAN/forge)** — a Claude Code plugin for React + TypeScript component libraries with self-documenting audit/create/edit/delete flows.
- **[edge-state-fixer](https://github.com/MUZEEBURRAHAMAN/edge-state-fixer)** — detects and designs the empty/loading/error/validation states AI generators skip; engine, web app, and MCP server.
- **[Cutcliply](https://cutcliply.up.railway.app/)** — smart auto-cropping video tool for exporting social-ready formats.
- **[Blobby](https://www.figma.com/community/plugin/1672948027574838944/blobby-editable-blob-generator)** — generative SVG blob-shape plugin for Figma.
- **Tooltips & Snackbars** — a Figma design-system kit for tooltips, snackbars, and empty states.
